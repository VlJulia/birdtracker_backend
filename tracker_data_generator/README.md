# Генератор пакетов для тестирования сервера

Скрипт `bird_traker_data_generator.py` изображает трекер: генерирует пакеты с данными датчиков и отправляет их на сервер по UDP.

## Что в папке

- `bird_traker_data_generator.py` - генератор.
- `.env.example` — адрес, порт и ключ.
- `requirements.txt` — список нужных библиотек.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка


```bash
cp .env.example .env
```

```ini
SERVER_IP=0.0.0.0
SERVER_PORT=9000
SECRET_KEY=ключ
```

Файл `.env` внесён в `.gitignore`.
## Запуск

#### Используются следующие флаги: 

| Флаг | По умолчанию | Что делает |
|------|--------------|------------|
| `-t`, `--type` | 1 | тип записи: 1 — батарея и солнце, 2 — координаты и датчики, 3 — синхронизация времени |
| `-n`, `--packets` | 5 | сколько пакетов отправить |
| `-r`, `--records` | 3 | сколько записей в одном пакете |
| `-d`, `--delay` | 0.2 | пауза между пакетами, секунды |
| `--ip` | из `.env` | адрес сервера |
| `-p`, `--port` | из `.env` | порт сервера |

Порт берётся из `SERVER_PORT` в `.env` (9000 по умолчанию). Если флаг `-p` указан, он важнее значения из `.env`.

Пример: отправить 10 пакетов с координатами и датчиками.

```bash
python3 bird_traker_data_generator.py --type 2 --packets 10 --records 5 --delay 0.1
```

Все флаги с описанием: `python3 bird_traker_data_generator.py -h`.
